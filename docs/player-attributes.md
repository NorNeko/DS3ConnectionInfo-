# 玩家属性显示

适配目标：Dark Souls III `1.15.2.0`，x64，Windows，.NET Framework 4.7.2。

## 使用

在 Settings 的原有列选择框中，或 Overlay 的原有列选择框中，找到 Location 后追加的项目：

1. 等级
2. 生命力
3. 集中力
4. 持久力
5. 力量
6. 敏捷
7. 智力
8. 信仰
9. 当前血量 / 最大生命值

选择字段后，使用原有开关控制显示/隐藏。主窗口与悬浮层同步显示/隐藏同一字段，以原有悬浮层选择作为升级时的依据。新增字段默认隐藏，旧字段的设置保持不变。每一行对应 Slot 1–5 的玩家，不使用游戏锁定目标。未加载或读取失败显示 `—`，死亡时可正常显示 `0 / 最大生命值`。

GitHub Release 使用 `artifacts/release/DS3ConnectionInfo-v4.5.0-cn.2-win-x64.exe` 单文件产物。启动器会将 `steam_api64.dll` 和 ETW x64 组件释放到固定的本地应用目录，然后启动实际程序。构建方法见 [BUILDING.md](../BUILDING.md)。关闭新程序、运行原来的工具即可回退；此功能不修改存档或角色数据。

## 读取与兼容性依据

本地正常工具的 SHA-256：`bbce38ed090af75b21b777273dfe2b046100a85c806ef4e5d25ae7af40432e93`。
通过静态反编译核对，其实现与上游 master (`24c71a6`) 不同：使用实际模块加载地址加偏移，并使用 1–5 的玩家槽位。

本次对齐的模块相对地址：

| 对象/函数 | 偏移 |
|---|---:|
| GameDataMan | `0x47572B8` |
| WorldChrMan | `0x477FDB8` |
| GameMan | `0x475AC00` |
| FrpgNetMan | `0x4756E48` |
| SprjSessionManager | `0x4796260` |
| 原有 ApplyEffect 调用 | `0x88F710` |
| 原有 LeaveSession 调用 | `0xDF7A00` |

已有功能的机器码模板在各自私有副本中填入实际地址，避免残留旧的绝对地址。新增属性展示只调用读取路径。

玩家链：`read64(BaseB)` → `read64(world + 0x40)` → `read64(array + 0x38 * slot)`。
角色属性对象为 `read64(character + 0x1FA0)`：从 `+0x44` 连续读取 48 字节，等级位于 `+0x70`，七项属性分别位于 `+0x44/48/4C/50/54/58/5C`。

血量使用同一个当前运行时对象：`read64(read64(character + 0x1F90) + 0x18)`，其 `+0xD8` 为当前 HP，`+0xDC` 为当前最大 HP。没有凭阵营选择 SessionInfo 的 `+0x1C/+0x20` 两种血量上限。血量不可读时，仍可显示已成功读取的加点属性。

每轮刷新先清空上一轮角色状态，再读取并重新核对角色指针及 Steam 身份，避免槽位复用导致旧属性串人。Windows 读取失败或短读会作为失败处理，不会把零填充缓冲区当作成功结果。

字段表示本地同步数据，尚不承诺在装备加成、密码联机降级或非标准客户端下等同于原始存档加点。

- 当时没有远端玩家，因此未完成远端数据及 Steam 身份关联的联机验收。
- 编译仍有上游 RuntimeInformation 依赖版本冲突警告（MSB3277）；合并产物离线加载与渲染检查通过。

## 界面语言（2026-09-07）

默认使用简体中文。在窗口右上角“界面语言 / Language”中选择“中文”或“English”，立即更新界面并保存选择，下次启动恢复已选语言。旧配置中没有语言字段时使用简体中文。

翻译覆盖页面、表头、字段下拉列表和说明、开关、阵营、状态与错误提示、悬浮层默认标题，以及颜色选择器。玩家名称、Steam ID、网络返回的地名和用户自定义格式不作为界面文案翻译；Windows 原生字体对话框和系统错误正文沿用操作系统语言。

切换语言不改变属性列显示选择或当前所选字段。恢复默认设置会同时恢复简体中文。设置页说明会自动换行，悬浮设置可滚动查看。

验证：23 项回归检查覆盖已有属性功能和实际中英窗口切换，并生成两种语言的设置页、悬浮设置页截图；独立测试进程验证语言保存和恢复。测试界面不启动 Steam、游戏轮询或快捷键服务。

## 字段配置优化（2026-09-07）

- 已删除上游 GitHub 新版本检测代码、启动检查任务和更新通知链接。软件不再为检查版本发起请求；原有地区查询等业务功能不受影响。
- 悬浮层设为显示的字段会立即出现在“联机玩家”列表；设为隐藏则从两处一起收起，不留下空白列。在“设置”页修改列开关也会同步到悬浮层。
- 在“联机玩家”列表拖动表头可调整字段位置，悬浮层同步使用该顺序。顺序、显隐和颜色均会保存。隐藏后再显示会恢复该字段已保存的位置。
- 在“悬浮显示”的字段下拉列表选择字段后，使用同一行的颜色选择器设置该字段的悬浮文字颜色。颜色按字段保存，不随列的位置或界面语言改变。
- 未指定字段颜色时保留原来的文字颜色、阵营颜色或延迟颜色规则；自定义颜色优先。点击旁边的“默认”按钮恢复原有规则。此项仅更改悬浮文字，不改变联机列表原有颜色。
- 旧版本的主窗口独立显隐偏好会由悬浮字段选择统一；此前的悬浮显示选择保留。没有顺序或颜色设置的旧配置使用原顺序和原颜色规则。

本轮验证：Debug 与最终合并 Release 的 36 项回归检查，覆盖已有属性读取及双语功能，并新增字段联动、排序恢复、颜色按字段绑定、恢复默认和真实悬浮单元格绘制。另以独立测试进程检查设置持久化。不自动触发入侵、退出会话或改变游戏数据。

最终发行版使用固定的 `%LOCALAPPDATA%\DS3ConnectionInfo\v4.5.0-cn.2\` 内部运行目录，使单文件从不同位置启动时仍复用同一套应用设置。
