# DS3ConnectionInfo v4.5.0-cn.1

适配 Dark Souls III 1.15.2 的首个中文增强版单文件发行。

## 更新内容

- 默认简体中文，可即时切换中文或 English。
- 新增等级、生命力、集中力、持久力、力量、敏捷、智力、信仰和当前/最大生命值。
- 联机玩家列表与悬浮层同步字段显隐和排序。
- 支持为每个悬浮字段设置独立文字颜色并恢复默认规则。
- 移除过时的启动版本检查和更新弹窗。
- 单个 Windows x64 EXE 包含所需应用文件和原生组件。

## 安装

下载 `DS3ConnectionInfo-v4.5.0-cn.1-win-x64.exe` 后直接运行。程序会请求管理员权限，以便使用 ETW 检测网络延迟。悬浮层需要游戏使用窗口化或无边框窗口模式。

首次运行会将内部组件释放到 `%LOCALAPPDATA%\DS3ConnectionInfo\v4.5.0-cn.1\`，不需要用户手动管理 DLL。系统需要可用的 .NET Framework 4.7.2 或更高兼容版本。

详细兼容范围、读取方式和已完成的验证见 [玩家属性显示说明](player-attributes.md)。
