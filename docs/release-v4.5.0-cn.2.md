# DS3ConnectionInfo v4.5.0-cn.2

本版本包含两项简体中文界面用词优化：

- `Late Packet %`：由“延迟回复比例”调整为“丢包率”。
- `REO Hotkey Effect`：由“宝珠快捷键模式”调整为“红眼球快捷键模式”。

其余功能与 `v4.5.0-cn.1` 一致，包括玩家属性与血量显示、双语切换、字段显隐和排序同步、逐字段悬浮文字颜色，以及单文件发行方式。

下载 `DS3ConnectionInfo-v4.5.0-cn.2-win-x64.exe` 后直接运行。首次运行会将内部组件释放到 `%LOCALAPPDATA%\DS3ConnectionInfo\v4.5.0-cn.2\`。系统需要可用的 .NET Framework 4.7.2 或更高兼容版本。
